How do I find my token?

Do this in a web browser, not the Discord desktop app — the app ships with developer tools disabled.

  1. Open discord.com/app and log in.
  2. Open developer tools: F12, or Ctrl+Shift+I (Cmd+Option+I on Mac).
  3. Go to the Network tab.
  4. Type api in the filter box.
  5. Click around in Discord — open a DM, switch channels — so requests appear. Reload the page if the list stays empty.
  6. Click any request to discord.com/api/v10/….
  7. Scroll to Request Headers and find the line labelled authorization:. The long string after it is your token.

That string is your account. Anyone holding it is logged in as you — no password, no 2FA. Never paste it into a website, a bot, a "token checker", or a script someone hands you: talking people into doing exactly that is the standard Discord account-theft scam, and it's why Discord prints a giant warning in the browser console. Changing your Discord password invalidates it instantly, which is your kill switch if it ever leaks.

Automating a user account is against Discord's Terms of Service and can get the account terminated. It is also the only way to delete your own DM messages — Discord provides no supported route. Your call.

A bot token can only delete messages the bot itself sent, in servers it has been added to. It cannot touch your personal DMs with other people. This is the route Discord supports.

  1. Open the Discord Developer Portal.
  2. New Application, give it a name, then open the Bot tab.
  3. Click Reset Token and copy the value it shows. You only get to see it once.
  4. Under Privileged Gateway Intents, enable Message Content Intent.
  5. Go to OAuth2 → URL Generator, tick bot, then the Read Messages/View Channels and Manage Messages permissions, and open the generated URL to add the bot to your server.
  6. Paste the token above and set Type to Bot.

Keep a bot token secret too — regenerate it in the portal if it leaks.

Why is there no "Sign in with Discord" button?

Because it would not work. Discord's OAuth2 sign-in issues a bearer token limited to the scopes you approve — identify, email, guilds and similar. None of them grant permission to read your message history or delete your messages, and Discord publishes no scope that does.

So an OAuth button could show your name and avatar, and nothing else. You would still need to supply a token afterwards to delete anything — one extra step for zero extra capability. It was left out deliberately rather than overlooked.

If you ever meet a site offering to clean your Discord messages via a "Login with Discord" button, treat it as a red flag. Either it does not do what it claims, or it is collecting a real token from you under the appearance of an official login.
